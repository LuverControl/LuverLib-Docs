# Glossário

| Termo | Significado |
| --- | --- |
| AutoBuilder | Configuração global do PathPlanner para criar comandos |
| AutoCloseable | Contrato Java com método `close()` para encerrar recursos |
| Backend | Implementação concreta do controle ou transporte |
| CANBus | Barramento CAN usado pelo dispositivo |
| Coast / Brake | Giro livre / freio elétrico ao parar |
| Duty cycle | Fração de acionamento da saída |
| Feedforward | Saída estimada pelo modelo, antes da correção por erro |
| Follower / Seguidor | Controlador que segue a saída de um líder |
| Heartbeat | Sinal periódico de que a supervisão continua presente |
| Homing | Procedimento para encontrar uma referência física conhecida |
| ID CAN | Endereço do dispositivo no barramento |
| LTV | Controlador usado nesta integração para drivetrain diferencial |
| MegaTag2 | Método de pose da Limelight que requer orientação externa recente |
| NetworkTables / NT4 | Comunicação de dados entre robô e aplicações |
| Odometria | Estimativa do movimento usando sensores do robô |
| Optional | Valor que pode estar presente ou ausente, sem inventar uma medição |
| Pathfinding | Cálculo de caminho até um destino |
| PID | Correção por erro proporcional, integral e derivativo |
| Pipeline | Conjunto de processamento selecionado na câmera |
| Pose | Posição e orientação em um referencial |
| RAM / Flash | Memória temporária / armazenamento persistente do controlador |
| Record | Tipo Java para agrupar dados com acesso por métodos |
| Requisito | Subsistema que um comando reserva para executar |
| RPM | Rotações por minuto |
| Scheduler | Gerenciador que atualiza subsistemas e executa comandos |
| Sendable | Objeto WPILib com propriedades publicáveis no painel |
| Setpoint / Referência | Valor desejado pelo controlador |
| Slot | Conjunto selecionável de parâmetros de controle no SPARK |
| Soft limit | Limite de posição implementado por configuração do controlador |
| Swerve | Tração com módulos que giram e tracionam independentemente |
| Tank / Diferencial | Tração com lados esquerdo e direito controlados separadamente |
| Trigger | Condição que pode agendar/cancelar comandos |
| Vendordep | Arquivo que declara bibliotecas de um fornecedor no projeto WPILib |
| Wrapper | Classe que organiza o acesso a outra API |
| WPILib | Conjunto de bibliotecas e ferramentas para FRC |
| wpilog | Formato de log de dados da WPILib |
| Yaw | Orientação de giro no plano horizontal |
